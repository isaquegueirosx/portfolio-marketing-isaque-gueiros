# Isaque Gueiros

## Portfólio de Marketing

Projetos desenvolvidos com foco em **marketing, organização comercial, análise de dados e comunicação**.

Este repositório reúne projetos práticos desenvolvidos para demonstrar organização, visão analítica e capacidade de estruturar materiais para diferentes necessidades de marketing e negócios.

---

## Projetos

### 01 — Campanha de Lançamento

Planejamento e estruturação de uma campanha de marketing para lançamento de empreendimento imobiliário.

**Principais entregas:**

* Estrutura de campanha
* Planejamento de comunicação
* Materiais de apoio
* Indicadores de acompanhamento

---

### 02 — Kit de Apoio Comercial

Desenvolvimento de materiais para organização e apresentação de informações de um empreendimento imobiliário.

**Principais entregas:**

* Apresentação comercial
* Ficha técnica
* Fluxo comercial
* Material de apoio à equipe de vendas

---

### 03 — Dashboard de Leads

Organização e análise de dados relacionados à geração e conversão de leads.

**Principais entregas:**

* Base de dados
* Indicadores comerciais
* Estrutura de funil
* Análise de leads e conversões

---
