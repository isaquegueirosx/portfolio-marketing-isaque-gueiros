# Campanha de Lançamento de Empreendimento

## Sobre o projeto

Projeto fictício desenvolvido para demonstrar a estruturação de uma campanha de marketing para o lançamento de um novo empreendimento imobiliário.

## Objetivo

Criar uma estratégia de lançamento capaz de gerar reconhecimento da marca, captar potenciais clientes e apoiar a equipe comercial.

## Estratégia

- Definição do público-alvo
- Planejamento da comunicação
- Criação de conteúdo para redes sociais
- Estruturação da campanha de mídia
- Organização dos leads
- Acompanhamento dos principais indicadores

## Canais

- Instagram
- Facebook
- Google
- Landing Page
- WhatsApp

## Indicadores acompanhados

- Alcance
- Impressões
- Cliques
- Leads
- Taxa de conversão
- Custo por lead

## Ferramentas

- Google Sheets
- Canva
- PowerPoint
- Excel
- Google Analytics

## Resultado esperado

Aumentar a visibilidade do empreendimento e criar um fluxo organizado de potenciais clientes para o time comercial.
